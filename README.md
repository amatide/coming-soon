# Coming Soon - Editama

A "Coming Soon" page with animated shader background built with React, TypeScript, and Tailwind CSS.

## Features

- Animated WebGL shader background
- Responsive design
- Trust badge, headline, subtitle, and CTA buttons
- Footer with social links

## Tech Stack

- React 19
- TypeScript
- Tailwind CSS v4
- Vite

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

This will start the development server at `http://localhost:5173`

### Build

```bash
npm run build
```

The built files will be in the `dist` directory.

### Preview Production Build

```bash
npm run preview
```

## Customization

Edit `src/App.tsx` to customize:

- Trust badge text and icons
- Headline text
- Subtitle text
- Button text and actions
- Footer links

## Deployment

The `dist` directory can be deployed to any static hosting service:

- GitHub Pages
- Vercel
- Netlify
- Cloudflare Pages
